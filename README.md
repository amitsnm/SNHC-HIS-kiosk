# SNHC HIS Kiosk

Sant Nirankari Health City patient self-service kiosk UI.

Touch-first home with service cards (no login wall). UHID / mobile / QR identity is requested only for services that need it.

## Run locally

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
npm run preview
```
